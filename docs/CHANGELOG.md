# 変更履歴

このプロジェクトのすべての重要な変更は、このファイルに記録されます。

フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に基づいており、
バージョン番号は [Semantic Versioning](https://semver.org/lang/ja/) に従っています。

## [Unreleased]

## [1.4.0] - 2026-10-30

### 追加
- 集計結果を画面に表示する「全体」「個人」タブ。全体は担当者×診療科の表と、診療科で色分けした担当者別の横棒グラフ
- 個人の集計。担当者ごとに合計、担当者1人あたりの平均、診療科別、文書名別の上位10件、月別件数のグラフを表示
- 各タブの「Excel出力・印刷」ボタン。全体はテンプレートに担当者別のグラフを加え、個人は新しいブックに表と月別グラフを書き、A4横1枚で印刷できる設定にして Excel で開く
- 依存パッケージに matplotlib を追加

### 変更
- 「集計開始」は集計結果を画面に表示するように変更。Excel への出力は「Excel出力・印刷」ボタンで行う
- データ読込で入れ替える範囲を、元データの預り日の最も古い日から最も新しい日までに変更。古い元データを読み込んでも、それより新しいデータベースの文書は残る
- 初期のウィンドウの大きさを 1250×760 に変更

## [1.3.0] - 2026-10-30

### 追加
- 担当者と診療科のマスタをデータベースに追加し、「マスタ」ボタンから編集する画面を追加。担当者は氏名・表示順・在籍・電子カルテID・権限を登録できる

### 変更
- 集計表に並べる担当者と診療科を、`config.ini` ではなくマスタから取るように変更。`ordered_names` と `clinical_departments` はマスタが空のときの初期値として使う
- 退職にした担当者は、期間内に件数がなければ集計表に出さないように変更
- マスタにない担当者名の行は、取り込まずにエラー行の一覧に出すように変更

## [1.2.0] - 2026-10-30

### 追加
- データベースを SQLite に変更。データベースが空なら、最初のデータ読込で旧データベースの xlsx を取り込む
- データ読込の前に、入れ替える範囲と削除・追加・除外の件数を確認するメッセージ
- 取り込めなかった行の一覧画面。コピーと CSV 保存ができる
- 起動時に1日1回データベースをバックアップし、`[Backup]` の `keep_generations` の世代数だけ残す
- ファイルパス設定に旧データベースの項目を追加

### 変更
- データ読込を範囲置き換えに変更。元データで最も古い預り日以降の文書を、元データの内容で入れ直す。元データで担当者を変えた行や削除した行も反映される
- 日付が読めない行と、医師依頼日が預り日より前の行は取り込まずに一覧に出すように変更
- 患者名・患者ID・備考を取り込まないように変更
- 集計を SQL で行うように変更し、依存パッケージから polars と pyarrow を削除

### 削除
- xlsx のデータベースへの書き込みと、データ読込のたびに行っていたバックアップ

## [1.1.1] - 2026-10-30

### 修正
- exe で起動したときに設定の保存が次回の起動で元に戻る問題。exe と同じフォルダの `config.ini` を使い、無ければ同梱の ini をコピーするように変更

## [1.1.0] - 2026-10-29

### 追加
- 年・年の始まり(1月始まり/4月始まり、初期値は4月始まり)・期間(月・四半期・上半期・下半期・一年)を選んで分析期間を自動入力する機能
- 元データ・データベース・バックアップ先・出力書式・出力先を画面から設定する「ファイルパス」ダイアログ
- データ読込の完了時に、データベースの件数を表示

### 変更
- 設計を作り直し、`service` を読み込み(`service_excel_reader`)・集計(`service_data_analyzer`)・書き出し(`service_excel_writer`)・統括(`service_medical_docs_analyzer`)に分割
- 処理中のエラーをコンソールに出して握りつぶすのをやめ、画面にエラーメッセージを表示するように変更
- 期間内にデータがない場合は、空の集計表を出力せずにメッセージを表示するように変更
- 元データとデータベースの列が一致しない場合は、データベースを元データだけで上書きせず、エラーを表示するように変更
- 日付を文字列ではなく日付型で扱い、`yyyy/mm/dd` 以外の手入力はエラーとして表示するように変更
- 「設定」ボタンは実行中の `config.ini` を開くように変更し、`[PATHS]` の `config_path` を廃止
- 画面の文言を `app/constants.py` にまとめ、全関数に型ヒントを追加

### 削除
- 未使用の `utils/utils.py`
- `service_data_processor.py`、`service_excel_handler.py`、`service_medical_docs_processor.py`(新しいモジュールへ統合)

### 修正
- `app/__init__.py` と `pyproject.toml` のバージョンの不一致
