# 変更履歴

このプロジェクトのすべての重要な変更は、このファイルに記録されます。

フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に基づいており、
バージョン番号は [Semantic Versioning](https://semver.org/lang/ja/) に従っています。

## [Unreleased]

## [1.17.0] - 2026-11-04

### 変更
- Excel 出力(全体・個人・全体推移・個人推移)の表の文字を 14pt、表題を 16pt にした。文字が切れないよう、行の高さと列幅も広げた

## [1.16.2] - 2026-11-04

### 修正
- 全体の Excel 出力を印刷すると、表とグラフが縦長なため高さに合わせて縮められ、A4 横の右半分が空いていた。表とグラフを合わせた形が A4 横の印刷範囲と同じ縦横比になるよう、グラフの幅を広げるようにした

## [1.16.1] - 2026-11-04

### 修正
- 全体の Excel 出力を印刷すると、診療科の見出しが途中で切れ、グラフが下と右(凡例)で切れていた。見出しの文字数に合わせて列幅を広げ、印刷範囲を指定せずにグラフまで含めて A4 横 1 枚に縮めて印刷するようにした

## [1.16.0] - 2026-11-04

### 追加
- 全体の Excel 出力の表の下に、担当者ごとの件数を診療科で色分けした積み上げ横棒グラフ(全体タブの図と同じ)を付けた

### 変更
- 集計対象を選び直すと、すぐに集計し直すようにした。元データは取り込まず、DB から全体推移・個人推移と、集計済みなら全体・個人を集計し直す。選んだ集計対象はその場で `[Analysis] document_type` に保存する
- 全体の Excel 出力をテンプレートなしで作るようにした。旧テンプレート `医療文書作成件数.xlsx` のレイアウト(シート名「一覧」・ＭＳ Ｐゴシック・罫線・中央揃え・行の高さ・ウィンドウ枠の固定)をコードで作り、印刷範囲は表とグラフに合わせる。`save_results` の引数は `(summary, output_dir)` にした

### 削除
- 設定 `[PATHS] template_path` と、設定画面の「出力書式」の欄を削除した。配布先の ini に残っていても使わない

## [1.15.0] - 2026-11-03

### 追加
- 画面左側の終了日と「集計開始」の間に「集計対象」の選択欄(全書類・医療文書・主治医意見書)を追加した。医療文書は主治医意見書を除いた全書類。「集計開始」で確定し、全体・個人・全体推移・個人推移の各タブと Excel 出力に反映する。初期値は全書類で、最後に集計した項目を `[Analysis] document_type` に保存して次回起動時に復元する
- Excel 出力(全体・個人・推移)の見出しとファイル名に集計対象の名前を入れた。画面の全体タブの見出しと個人タブの合計にも出す

### 変更
- 年の欄の上下矢印ボタンを削除した。年を入力して Enter を押すか欄を離れると、期間に合わせて開始日・終了日が入る
- `DocumentFilter` の `opinion_only` を `document_type` にした。見本 `source_golden.json` の `opinion_by_staff` を集計対象ごとの件数 `by_document_type` にした

### 削除
- 全体タブの最後の列・個人タブの診療科別の最後の行・推移タブの診療科の選択欄から「主治医意見書」を削除した(集計対象で選ぶため)

## [1.14.0] - 2026-11-03

### 追加
- 全体タブの最後の列・個人タブの診療科別・推移タブの選択欄に「主治医意見書」を追加した。文書名に「主治医意見書」を含む文書を診療科を問わず数える(もとの診療科の列にも数えるため、合計には足さない)
- マスタで「合計」「主治医意見書」を診療科の名前に登録できないようにした
- 元データの読み取りと集計の見本 `tests/fixtures/source_golden.json` を追加した(C# 移植版と結果を比べるため)

### 変更
- 元データを、`[PATHS] source_dir` のフォルダにある `…_YYYYMMDDhhmm.xlsm` のうちファイル名の日時が最新のものにした(`source_file_path` は使わない。既定は `C:\Shinseikai\MediDocsAnalyzer`)。設定画面ではフォルダを選ぶ
- 起動時の自動集計では、取り込めなかった行の一覧を表示しないようにした(「集計開始」「Excel読込」では従来どおり表示する)
- DB のスキーマの版を `PRAGMA user_version` で持つようにした。新しい版の DB は開かない
- 推移の診療科の絞り込みを、画面の文言ではなく `DocumentFilter` でサービスへ渡すようにした
- 年の始まりの月の既定値を、同梱の `config.ini` と同じ 1 にした。同梱の `clinical_departments` から「合計」を除いた

## [1.9.0] - 2026-11-01

- 概要タブに、診療科ごとの未着手・未完了・担当不明・合計の件数の表を追加した。その下に、これまでどおり行の一覧を表示する

### 変更

- 個人タブの文書名は、上位10件だけでなく全件をスクロールして見られるようにした(表示は10行)。個人の Excel 出力は A4 1 枚に収めるため、これまでどおり上位10件

- 設定画面の数値の項目から、値を1ずつ上げ下げする上下ボタンを削除した

## [1.8.0] - 2026-10-31

### 追加
- 「概要」タブを「全体」タブの左に追加した。預り日が本日を含めて直近の数日以内で、担当者名または医師依頼日が空の行(下書き)の件数と一覧を、預り日の新しい順に表示する。担当者が決まっていない文書や依頼が済んでいない文書を見つけて、業務の割り振りに使うため
- 概要は起動時と集計開始のときに元データから更新する。下書きは元データの編集で変わり続けるため、データベースには保存しない。起動時に元データを読めないときは、ダイアログを出さずに概要タブの見出しにエラーを表示する
- 職員でログインしたときも概要タブを表示する
- 設定画面に「概要で確認する日数」(`[Overview] pending_days`、1〜365、既定は7)を追加した

## [1.7.0] - 2026-10-31

## [1.3.0] - 2026-10-30

### 追加
- 担当者と診療科のマスタをデータベースに追加し、「マスタ」ボタンから編集する画面を追加。担当者は氏名・表示順・在籍・電子カルテID・権限を登録できる

### 変更
- 集計表に並べる担当者と診療科を、`config.ini` ではなくマスタから取るように変更。`ordered_names` と `clinical_departments` はマスタが空のときの初期値として使う
- 退職にした担当者は、期間内に件数がなければ集計表に出さないように変更
- マスタにない担当者名の行は、取り込まずにエラー行の一覧に出すように変更

## [1.2.0] - 2026-10-30

### 追加
- データベースを SQLite に変更。データベースが空なら、最初のデータ読込で旧データベースの xlsx を取り込む
- データ読込の前に、入れ替える範囲と削除・追加・除外の件数を確認するメッセージ
- 取り込めなかった行の一覧画面。コピーと CSV 保存ができる
- 起動時に1日1回データベースをバックアップし、`[Backup]` の `keep_generations` の世代数だけ残す
- ファイルパス設定に旧データベースの項目を追加

### 変更
- データ読込を範囲置き換えに変更。元データで最も古い預り日以降の文書を、元データの内容で入れ直す。元データで担当者を変えた行や削除した行も反映される
- 日付が読めない行と、医師依頼日が預り日より前の行は取り込まずに一覧に出すように変更
- 患者名・患者ID・備考を取り込まないように変更
- 集計を SQL で行うように変更し、依存パッケージから polars と pyarrow を削除

### 削除
- xlsx のデータベースへの書き込みと、データ読込のたびに行っていたバックアップ

## [1.1.1] - 2026-10-30

### 修正
- exe で起動したときに設定の保存が次回の起動で元に戻る問題。exe と同じフォルダの `config.ini` を使い、無ければ同梱の ini をコピーするように変更

## [1.1.0] - 2026-10-29

### 追加
- 年・年の始まり(1月始まり/4月始まり、初期値は4月始まり)・期間(月・四半期・上半期・下半期・一年)を選んで分析期間を自動入力する機能
- 元データ・データベース・バックアップ先・出力書式・出力先を画面から設定する「ファイルパス」ダイアログ
- データ読込の完了時に、データベースの件数を表示

### 変更
- 設計を作り直し、`service` を読み込み(`service_excel_reader`)・集計(`service_data_analyzer`)・書き出し(`service_excel_writer`)・統括(`service_medical_docs_analyzer`)に分割
- 処理中のエラーをコンソールに出して握りつぶすのをやめ、画面にエラーメッセージを表示するように変更
- 期間内にデータがない場合は、空の集計表を出力せずにメッセージを表示するように変更
- 元データとデータベースの列が一致しない場合は、データベースを元データだけで上書きせず、エラーを表示するように変更
- 日付を文字列ではなく日付型で扱い、`yyyy/mm/dd` 以外の手入力はエラーとして表示するように変更
- 「設定」ボタンは実行中の `config.ini` を開くように変更し、`[PATHS]` の `config_path` を廃止
- 画面の文言を `app/constants.py` にまとめ、全関数に型ヒントを追加

### 削除
- 未使用の `utils/utils.py`
- `service_data_processor.py`、`service_excel_handler.py`、`service_medical_docs_processor.py`(新しいモジュールへ統合)

### 修正
- `app/__init__.py` と `pyproject.toml` のバージョンの不一致
