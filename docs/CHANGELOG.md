# 変更履歴

このプロジェクトのすべての重要な変更は、このファイルに記録されます。

フォーマットは [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) に基づいており、
バージョン番号は [Semantic Versioning](https://semver.org/lang/ja/) に従っています。

## [Unreleased]

## [1.11.0] - 2026-11-01

### 変更
- 全体推移タブのレイアウトを「診療科 [選択欄]　範囲 [開始日] ～ [終了日]　Excel出力」の 1 行にした
  - 診療科はタブではなく選択欄で選ぶ
  - 範囲は開始年〜終了年ではなく開始日〜終了日で選ぶ。医師依頼日が範囲内の文書だけを数え、範囲外の月は空欄にする。左側の分析期間とは連動しない
  - 設定ファイルの `[Trend]` には `start_date` / `end_date` を保存する(旧版の `start_year` / `end_year` は保存時に消す)。既定は前年(年度)の初日〜本日
  - 今月は途中までの件数のまま表示する
- 折れ線グラフで、件数が 0 件の月は線を引かないようにした(画面と Excel 出力の両方)。Excel では表は 0 のまま、グラフ用の値を隠しシート「グラフ用」に置いて 0 を空欄にしている
- 全体推移の Excel のファイル名と見出しを、年ではなく範囲の日付にした

## [1.10.0] - 2026-11-01

### 追加
- 「全体推移」タブを「個人」タブの右に追加した。データベースの文書を医師依頼日で年(年度)ごとの月別に数え、表と、1 年 1 本の折れ線グラフで表示する。過去の年と件数を比べられるようにするため
  - 診療科はタブで選ぶ(先頭は全診療科の「合計」)。範囲は開始年〜終了年で選び、選んだ年数だけ表の行と折れ線が増える。既定は前年と今年
  - 選んだ開始年・終了年・診療科は設定ファイルの `[Trend]` に保存し、次回の起動時にも同じ表示にする
  - 本日より後の月は空欄にし、線を引かない
  - 「Excel出力」で、選んでいる診療科の表と折れ線グラフを A4 横 1 枚に出力する
  - 職員でログインしたときは表示しない

### 変更
- 個人タブの月別件数のグラフを、棒グラフから折れ線グラフに変えた(画面と Excel 出力の両方)

### 削除
- 全体の Excel 出力からグラフを削除した。表だけを出力する
- 個人タブと個人の Excel 出力から「担当者1人あたりの平均」を削除した

## [1.9.0] - 2026-11-01

### 追加
- 起動時に、前回集計した期間(`[Analysis] start_date / end_date`)が設定に残っていれば、「集計開始」と同じく元データを取り込んでから自動で集計する。起動するたびに「集計開始」を押さなくて済むようにするため
- 概要タブに、診療科ごとの未着手・未完了・担当不明・合計の件数の表を追加した。その下に、これまでどおり行の一覧を表示する

### 変更
- 概要の「空欄の項目」列を「現在の状態」に変えた。担当者名と医師依頼日が両方空なら「未着手」、医師依頼日だけ空なら「未完了」、担当者名だけ空なら「担当不明」と表示する。見出しの「対象●件」の後ろも同じ 3 つの件数にそろえた
- 個人タブの文書名は、上位10件だけでなく全件をスクロールして見られるようにした(表示は10行)。個人の Excel 出力は A4 1 枚に収めるため、これまでどおり上位10件
- 設定画面で保存したら、概要をすぐ読み直すようにした(概要で確認する日数・元データのパスの変更を反映する)
- 設定画面の数値の項目から、値を1ずつ上げ下げする上下ボタンを削除した

## [1.8.0] - 2026-10-31

### 追加
- 「概要」タブを「全体」タブの左に追加した。預り日が本日を含めて直近の数日以内で、担当者名または医師依頼日が空の行(下書き)の件数と一覧を、預り日の新しい順に表示する。担当者が決まっていない文書や依頼が済んでいない文書を見つけて、業務の割り振りに使うため
- 概要は起動時と集計開始のときに元データから更新する。下書きは元データの編集で変わり続けるため、データベースには保存しない。起動時に元データを読めないときは、ダイアログを出さずに概要タブの見出しにエラーを表示する
- 職員でログインしたときも概要タブを表示する
- 設定画面に「概要で確認する日数」(`[Overview] pending_days`、1〜365、既定は7)を追加した

## [1.7.0] - 2026-10-31

### 変更
- 「設定」ボタンで、メモ帳ではなく設定画面を開くようにした。ファイルパス・画面の幅と高さ・バックアップの保存世代数を変更できる。数値は範囲内の整数だけを保存し、誤った値を入力したときはエラーを表示する
- 「ファイルパス」画面を設定画面にまとめ、「ファイルパス」ボタンを削除した。分析期間・年の始まり、担当者・診療科の初期値はメイン画面とマスタで変えるため、設定画面には出さない
- 取り込めなかった行の「CSV保存」は、保存先を選ばずに出力先フォルダへ `取込エラー行_yyyymmdd_HHmmss.csv` で保存し、そのフォルダを開くようにした
- 「Excel出力・印刷」ボタンの名前を「Excel出力」に変えた。保存したあとは Excel を開かず、出力先フォルダを開く(同じフォルダの窓が開いていれば、新しい窓は開かない)

## [1.6.0] - 2026-10-31

### 追加
- 患者IDの取り込み。院内だけで使うため、データベースに保存する。古いデータベースには起動時に列を追加する
- 「取り込めなかった行」の一覧に患者IDの列を追加(コピー・CSV保存にも含む)
- 全体の表で「合計」と各診療科の見出しを押すと並べ替える。もう一度押すと昇順と降順が切り替わり、合計行はいつも一番下に残る

### 変更
- 「集計開始」は、元データ(xlsm)を確認なしで取り込んでから集計する。職員も取り込みを含めて使える
- 「データ読込」ボタンを「Excel読込」に変え、旧データベース(xlsx)を取り込むだけにした。位置は「ファイルパス」と「設定」の間
- 「マスタ」ボタンの名前を「マスタ設定」に変更

### 削除
- データベースが空のときに旧データベースを自動で取り込む処理。「Excel読込」で取り込む

## [1.5.0] - 2026-10-30

### 追加
- 電子カルテIDとパスワードによるログイン。パスワードを設定した在籍中の管理者がいると、起動時にログインを求める
- マスタ画面の「仮パスワード発行」ボタン。最初のログインで本人が新しいパスワードに変更する
- ログイン中の利用者がパスワードを変更する「パスワード変更」ボタン
- 権限による制限。職員は自分の個人集計だけを表示でき、データ読込・マスタ・ファイルパス・設定は使えない

### 変更
- タイトルバーにログイン中の担当者名を表示

## [1.4.0] - 2026-10-30

### 追加
- 集計結果を画面に表示する「全体」「個人」タブ。全体は担当者×診療科の表と、診療科で色分けした担当者別の横棒グラフ
- 個人の集計。担当者ごとに合計、担当者1人あたりの平均、診療科別、文書名別の上位10件、月別件数のグラフを表示
- 各タブの「Excel出力・印刷」ボタン。全体はテンプレートに担当者別のグラフを加え、個人は新しいブックに表と月別グラフを書き、A4横1枚で印刷できる設定にして Excel で開く
- 依存パッケージに matplotlib を追加

### 変更
- 「集計開始」は集計結果を画面に表示するように変更。Excel への出力は「Excel出力・印刷」ボタンで行う
- データ読込で入れ替える範囲を、元データの預り日の最も古い日から最も新しい日までに変更。古い元データを読み込んでも、それより新しいデータベースの文書は残る
- 初期のウィンドウの大きさを 1250×760 に変更

## [1.3.0] - 2026-10-30

### 追加
- 担当者と診療科のマスタをデータベースに追加し、「マスタ」ボタンから編集する画面を追加。担当者は氏名・表示順・在籍・電子カルテID・権限を登録できる

### 変更
- 集計表に並べる担当者と診療科を、`config.ini` ではなくマスタから取るように変更。`ordered_names` と `clinical_departments` はマスタが空のときの初期値として使う
- 退職にした担当者は、期間内に件数がなければ集計表に出さないように変更
- マスタにない担当者名の行は、取り込まずにエラー行の一覧に出すように変更

## [1.2.0] - 2026-10-30

### 追加
- データベースを SQLite に変更。データベースが空なら、最初のデータ読込で旧データベースの xlsx を取り込む
- データ読込の前に、入れ替える範囲と削除・追加・除外の件数を確認するメッセージ
- 取り込めなかった行の一覧画面。コピーと CSV 保存ができる
- 起動時に1日1回データベースをバックアップし、`[Backup]` の `keep_generations` の世代数だけ残す
- ファイルパス設定に旧データベースの項目を追加

### 変更
- データ読込を範囲置き換えに変更。元データで最も古い預り日以降の文書を、元データの内容で入れ直す。元データで担当者を変えた行や削除した行も反映される
- 日付が読めない行と、医師依頼日が預り日より前の行は取り込まずに一覧に出すように変更
- 患者名・患者ID・備考を取り込まないように変更
- 集計を SQL で行うように変更し、依存パッケージから polars と pyarrow を削除

### 削除
- xlsx のデータベースへの書き込みと、データ読込のたびに行っていたバックアップ

## [1.1.1] - 2026-10-30

### 修正
- exe で起動したときに設定の保存が次回の起動で元に戻る問題。exe と同じフォルダの `config.ini` を使い、無ければ同梱の ini をコピーするように変更

## [1.1.0] - 2026-10-29

### 追加
- 年・年の始まり(1月始まり/4月始まり、初期値は4月始まり)・期間(月・四半期・上半期・下半期・一年)を選んで分析期間を自動入力する機能
- 元データ・データベース・バックアップ先・出力書式・出力先を画面から設定する「ファイルパス」ダイアログ
- データ読込の完了時に、データベースの件数を表示

### 変更
- 設計を作り直し、`service` を読み込み(`service_excel_reader`)・集計(`service_data_analyzer`)・書き出し(`service_excel_writer`)・統括(`service_medical_docs_analyzer`)に分割
- 処理中のエラーをコンソールに出して握りつぶすのをやめ、画面にエラーメッセージを表示するように変更
- 期間内にデータがない場合は、空の集計表を出力せずにメッセージを表示するように変更
- 元データとデータベースの列が一致しない場合は、データベースを元データだけで上書きせず、エラーを表示するように変更
- 日付を文字列ではなく日付型で扱い、`yyyy/mm/dd` 以外の手入力はエラーとして表示するように変更
- 「設定」ボタンは実行中の `config.ini` を開くように変更し、`[PATHS]` の `config_path` を廃止
- 画面の文言を `app/constants.py` にまとめ、全関数に型ヒントを追加

### 削除
- 未使用の `utils/utils.py`
- `service_data_processor.py`、`service_excel_handler.py`、`service_medical_docs_processor.py`(新しいモジュールへ統合)

### 修正
- `app/__init__.py` と `pyproject.toml` のバージョンの不一致
