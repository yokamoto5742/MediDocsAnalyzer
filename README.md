# 医療文書集計アプリ

## 概要
医療文書集計アプリは、医療文書担当一覧(Excel)をデータベース(SQLite)に取り込み、指定期間内の文書作成件数を担当者別・診療科別に集計して、画面の表とグラフで表示するWindows向けデスクトップツールです。集計結果はグラフ付きのExcelに出力して印刷できます。

## ✨ 主な機能
- 元データをデータベースに取り込み、元データの預り日の範囲を入れ替える(担当者の変更や行の削除も反映)
- 取り込めなかった行(日付の誤りなど)を一覧で表示し、コピー・CSV保存
- 年と期間(月・四半期・上半期・下半期・一年)を選ぶだけで、分析期間を自動入力(1月始まり/4月始まりを選択可能)
- 「全体」タブ: 担当者×診療科の件数表と、担当者別の横棒グラフ
- 「個人」タブ: 担当者ごとの合計・平均・診療科別・文書名別上位10件・月別グラフ
- 全体・個人の集計をグラフ付きのExcel(A4横1枚)に出力して印刷
- 担当者・診療科のマスタ編集
- 起動時に1日1回データベースをバックアップ(世代数を設定可能)
- 電子カルテIDとパスワードによるログイン(管理者・職員の2つの権限)

## 動作要件
- Windows OS
- Python 3.13以上
- [uv](https://docs.astral.sh/uv/)
- 依存パッケージ(詳細は `pyproject.toml` を参照): babel, matplotlib, openpyxl, tkcalendar

## インストール方法
1. リポジトリをクローンまたはダウンロードします
2. プロジェクトフォルダで依存パッケージをインストールします
   ```bash
   uv sync
   ```
3. `utils/config.ini` の `[PATHS]` セクションを環境に合わせて設定します(起動後に「ファイルパス」ボタンからも設定できます)

## 使用方法
アプリケーションを起動します。
```bash
uv run python main.py
```

1. 「データ読込」ボタンで、元データをデータベースに取り込みます。入れ替える範囲と件数を確認してから取り込みます
2. 「年」「年の始まり(1月始まり/4月始まり)」「期間」を選ぶと、開始日・終了日が自動で入ります(日付欄に `yyyy/mm/dd` 形式で直接入力することもできます)
3. 「集計開始」ボタンで、右側の「全体」「個人」タブに集計結果が表示されます
4. 印刷するときは、各タブの「Excel出力・印刷」ボタンでExcelを開き、Excelから印刷します

| ボタン | 動作 |
|---|---|
| データ読込 | 元データをデータベースに取り込みます。取り込めなかった行があれば一覧を表示します |
| 集計開始 | 入力された期間で集計し、画面に表示します。期間は次回起動時に復元されます |
| マスタ | 担当者(氏名・表示順・在籍・電子カルテID・権限)と診療科を編集し、仮パスワードを発行します |
| ファイルパス | 元データ・データベース・旧データベース・バックアップ先・出力書式・出力先を選択して保存します |
| 設定 | `config.ini` をメモ帳で開きます |
| パスワード変更 | ログイン中の利用者のパスワードを変更します(ログインしたときだけ表示) |
| 閉じる | アプリを終了します |

## ログインと権限
- 最初はログインなしで起動し、すべての操作ができます
- マスタ画面で管理者に電子カルテIDを登録し、「仮パスワード発行」を押すと、次回の起動からログインが必要になります
- 仮パスワードでログインすると、新しいパスワード(6文字以上)への変更を求めます
- 職員は自分の個人集計の表示とExcel出力だけができます。データ読込・マスタ・ファイルパス・設定は使えません
- データベースを開けないときは、ファイルパスを直せるようログインなしで起動します

## 入力ファイルの形式
- 1行目が見出し、2行目以降がデータです。見出し名で列を探すので、列の順番や余分な列は問いません
- 必要な列: `預り日`、`文書名`、`診療科`、`医師名`、`担当者名`、`医師依頼日`
- 日付は日付型・Excelのシリアル値・`yyyy/mm/dd` 形式の文字列のどれでも読み込めます
- 患者名・患者ID・備考は取り込みません

## データ処理の流れ
1. データ読込
   - 元データの預り日の最も古い日から最も新しい日までにある文書を、データベースから消して元データの内容で入れ直します。範囲外の文書は残ります
   - 医師依頼日または担当者名が空の行は下書きとして取り込みません
   - 日付が読めない行、医師依頼日が預り日より前の行、マスタにない担当者名の行は取り込まずに一覧に出します
   - データベースが空のときは、先に旧データベース(xlsx)を取り込みます
2. 集計開始
   - データベースから、預り日が期間内(両端を含む)の文書を集計します
   - 退職にした担当者は、期間内に件数があるときだけ表示します
3. バックアップ
   - 起動時にその日のバックアップがなければ `backup_dir` に `{データベース名}_{yyyymmdd}.db` を作り、`keep_generations` を超えた古いものを削除します

## 設定ファイル
設定は `utils/config.ini` の1つだけです。ビルドした exe では、exe と同じフォルダの `config.ini` を使います(無ければ同梱のものをコピーします)。

| セクション | キー | 内容 |
|---|---|---|
| `[Appearance]` | `window_width` / `window_height` | ウィンドウの幅・高さ(px) |
| `[PATHS]` | `source_file_path` | 元データ(医療文書担当一覧)のパス |
| | `database_path` | データベース(SQLite)のパス。共有フォルダに置けます |
| | `legacy_database_path` | 旧データベース(xlsx)のパス。データベースが空のときだけ使います |
| | `backup_dir` | データベースのバックアップ先フォルダ |
| | `template_path` | 全体の出力書式(テンプレートExcel)のパス |
| | `output_dir` | 集計結果の出力先フォルダ |
| `[Backup]` | `keep_generations` | 残すバックアップの数(既定は30) |
| `[Analysis]` | `start_date` / `end_date` | 前回の分析期間(アプリが自動で更新) |
| | `year_start_month` | 年の始まりの月(1 または 4)(アプリが自動で更新) |
| | `ordered_names` | マスタが空のときに登録する担当者(カンマ区切り) |
| | `clinical_departments` | マスタが空のときに登録する診療科(カンマ区切り。`合計` は除いて登録) |

## 集計結果のExcel
### 全体
- A1: `医療文書作成件数 {最初の預り日}-{最後の預り日}`
- 2行目: `氏名`、`合計`、マスタの診療科
- 3行目以降: 担当者ごとの件数。`合計` 列はマスタの診療科の合計
- 最終行: 診療科ごとの合計。`合計` 列は一覧にない担当者・診療科も含めた全体の件数
- 表の下に担当者別の積み上げ横棒グラフ
- ファイル名: `医療文書作成件数{最初の預り日}-{最後の預り日}.xlsx`

### 個人
- 合計と担当者1人あたりの平均、診療科別・文書名別(上位10件)・月別の件数、月別グラフ
- ファイル名: `医療文書作成件数_{氏名}_{開始日}-{終了日}.xlsx`

## 開発者向け情報
### 開発コマンド
```bash
uv run pyright                       # 型チェック
uv run pytest tests/ -v --tb=short  # テスト(全件)
uv run python build.py               # exe のビルド
```

### データフロー
1. `main.py` がログインの要否を確かめ、必要ならログイン画面を出してから `MedicalDocsAnalyzerGUI` を表示する
2. `MedicalDocsAnalyzerGUI` がユーザー入力を受け取り、`MedicalDocsAnalyzer` の `prepare_import` / `apply_import` / `overall_summary` / `staff_summary` / `run_analysis` / `export_staff` を呼び出す
3. `MedicalDocsAnalyzer` が設定を読み込み、`service_excel_reader` で読み込み、`service_database` に書き、`service_data_analyzer` で集計する
4. `service_excel_writer` が集計結果をExcelに書き出し、Excelで開く

## トラブルシューティング
1. 「元データにデータがありません。」と表示される
   - 「ファイルパス」で元データのパスが正しいか確認
2. 「取り込めなかった行」が表示される
   - 一覧の行番号を元データで確認して直し、もう一度データ読込を実行。担当者名がマスタにない場合は、マスタに登録
3. 「指定された期間内のデータがありません。」と表示される
   - 先に「データ読込」を実行したか確認
4. Excelが保存できない
   - 同名の結果ファイルをExcelで開いたままだと保存できないため、閉じてから再実行
5. ログインできない
   - 管理者がマスタ画面で仮パスワードを発行し直す
